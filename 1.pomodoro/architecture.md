# ポモドーロタイマーWebアプリ アーキテクチャ案

## 1. 概要
FlaskとHTML/CSS/JavaScriptを用いたポモドーロタイマーWebアプリ。UIはモック画像に準拠。

## 2. ディレクトリ構成例
```
1.pomodoro/
  app.py           # Flaskアプリ本体
  timer.py         # タイマー/ポモドーロロジック（テストしやすい分離）
  db.py            # データ管理（必要なら）
  templates/
    index.html     # メイン画面
  static/
    css/
      style.css
    js/
      timer.js     # タイマー管理・UI操作
  tests/
    test_timer.py  # Pythonユニットテスト
    test_app.py    # Flaskルート/APIテスト
```

## 3. フロントエンド
- HTML：タイマー表示、操作ボタン、ポモドーロ回数や休憩表示
- CSS：モック画像に合わせたレイアウト・配色・レスポンシブ対応
- JavaScript：タイマーのカウントダウン、状態管理、通知や音

## 4. バックエンド（Flask）
- ルート設計：
  - `/`：メイン画面
  - `/api/start` `/api/stop` `/api/reset`：タイマー操作API
  - `/api/status`：タイマー状態取得API
- 状態管理：
  - 基本はフロント側で管理。ユーザーごとに状態保存が必要ならセッションやDB利用
- テンプレート：Jinja2でHTMLを動的生成

## 5. データ管理
- シンプルな場合はフロントのみで完結
- 履歴や統計を保存する場合はSQLite等DBを導入し、FlaskでCRUD APIを用意

## 6. ユニットテストのしやすさへの配慮
- タイマーやポモドーロ管理ロジックをPythonのクラス・関数として分離し、テストしやすくする
- API設計を明確化し、FlaskのテストクライアントでAPI単体テストが可能
- DBアクセス部分もモジュール化し、モックやテスト用DBでテストしやすく
- JavaScript側も関数・クラスで分割し、Jest等でユニットテスト可能な構造に
- DIやモックを活用し、外部依存を排除したテスト設計

## 7. 拡張案
- ユーザー認証（Flask-Login等）
- 履歴・統計表示
- 通知や音の追加
- モバイル対応

---
このアーキテクチャにより、UIモックに忠実なWebアプリを効率よく開発でき、ユニットテストや保守性も高められます。
