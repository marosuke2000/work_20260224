# ポモドーロタイマー with ゲーミフィケーション

集中力を高めながら、レベルアップやバッジ獲得でモチベーションを維持できるポモドーロタイマーアプリケーションです。

## 主な機能

### 🎮 ゲーミフィケーション要素

1. **経験値（XP）システム**
   - ポモドーロ完了ごとに50 XP獲得
   - レベル1からレベル10まで成長可能
   - レベルアップ時に特別な通知

2. **達成バッジシステム**
   - 🎯 初めてのポモドーロ完了
   - 🔥 3日連続でポモドーロ実施
   - ⚡ 7日連続でポモドーロ実施
   - 🌟 今週10回完了
   - 🏆 累計50回完了
   - 👑 累計100回完了
   - 🎖️ レベル5到達
   - 💎 レベル10到達

3. **ストリーク表示**
   - 連続実施日数をカウント
   - 現在のストリークと最長ストリークを表示
   - モチベーション維持に貢献

4. **週間/月間統計**
   - セッション完了数
   - 総集中時間
   - 平均集中時間
   - 完了率の算出

## セットアップ

### 必要な環境
- Python 3.7以上

### インストール手順

1. 必要なパッケージをインストール：
```bash
cd 1.pomodoro
pip install -r requirements.txt
```

2. アプリケーションを起動：
```bash
python app.py
```

3. ブラウザで以下のURLにアクセス：
```
http://localhost:5000
```

## 使い方

1. **タイマーの使用**
   - 「スタート」ボタンでポモドーロ（25分）を開始
   - 「一時停止」で中断、「リセット」で初期状態に戻す
   - タイマー完了でXPとバッジを獲得

2. **統計の確認**
   - 週間統計/月間統計タブで切り替え可能
   - セッション数、総時間、平均時間、完了率を表示

3. **バッジコレクション**
   - 達成したバッジは黄色く表示される
   - 未達成のバッジは半透明で表示

## データ保存

- すべてのデータはSQLiteデータベース（`pomodoro.db`）に保存されます
- データベースは自動的に作成され、初期化されます

## 技術スタック

- **バックエンド**: Flask（Python）
- **データベース**: SQLite + SQLAlchemy
- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript
- **デザイン**: レスポンシブデザイン、グラデーション背景
